# Tredecadia

[English](README.md) · **Українська** · [Усі мови](README.languages.md)

Tredecadia — відкритий проєкт вічного календаря з **13 місяцями по 28 днів**. Кожен місяць має рівно чотири повні тижні, одна й та сама дата завжди припадає на той самий день тижня, а дні, що вирівнюють тривалість року, винесені за межі місяців і семиденного тижня.

> **Поточна публічна версія: `1.0.0`.**

## Як це працює

- 13 × 28 = 364 звичайні дні всередині місяців.
- Кожен місяць — рівно чотири повні тижні.
- День `01` завжди **Mene (`W1`)**, `28` — **Toze (`W7`)**.
- `EQ` — **День рівнодення / Новий рік** — відкриває рік і не належить ані місяцю, ані тижню.
- У високосний рік після `13-28` додається `ED` — **День Землі** — і лише потім настає наступний `EQ`.

Канонічний семиденний цикл:

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

Це канонічні ідентифікатори Tredecadia, а не переклади чи перейменування понеділка–неділі. RC2 ще не визначає перевірених локалізованих псевдонімів для днів тижня, тому використовуються канонічні латинські форми.

Звичайний рік:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

Високосний рік:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Ера Tredecadia

Tredecadia використовує одну безперервну цілочисельну шкалу років зі справжнім **нулевим роком**. Усередині календаря немає потреби ділити час на дві окремі ери.

Англійські скорочення **BCE/CE** означають **Before Common Era / Common Era**. Українською це відповідає поняттям **«до нашої ери / наша ера»**, тобто **до н. е. / н. е.**

Математичний початок координат:

`TE 00000-EQ ↔ астрономічний григоріанський рік -9999, 20 березня`

У звичному історичному записі це **10000 рік до н. е. (`10000 BCE`)**. Дата не проголошується «початком людства», цивілізації чи будь-якого історичного процесу — це лише математичний нуль шкали Tredecadia.

Для цивільного перетворення:

`рік TE = астрономічний григоріанський рік + 9999`

Тому 2026 рік н. е. відповідає **TE 12025**.

## Формат дат

Канонічний машинний формат використовує лише ASCII і щонайменше п’ять цифр у полі року:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

У людському інтерфейсі початкові нулі можна не показувати, а для від’ємних років використовувати типографський мінус. Це лише спосіб відображення, а не інший канонічний формат.

## Місяці

Назви місяців є міжнародними ідентифікаторами. Для української поки немає окремого перевіреного профілю написання кирилицею, тому в таблиці навмисно збережено канонічну латиницю.

| № | Повна назва | Скорочення на 3 склади (`Short-6`) | Розмовна форма на 2 склади (`Short-4`) |
|---:|---|---|---|
| 01 | Masanumika | Masanu | Masa |
| 02 | Tasuzunumu | Tasuzu | Tasu |
| 03 | Nazumasanu | Nazuma | Nazu |
| 04 | Mikasumani | Mikasu | Mika |
| 05 | Yanimuzunu | Yanimu | Yani |
| 06 | Zumitanasu | Zumita | Zumi |
| 07 | Muyasanumi | Muyasa | Muya |
| 08 | Sunizusaka | Sunizu | Suni |
| 09 | Numanamuta | Numana | Numa |
| 10 | Kazunusuya | Kazunu | Kazu |
| 11 | Yanazumasa | Yanazu | Yana |
| 12 | Sanumikazu | Sanumi | Sanu |
| 13 | Nimutazuna | Nimuta | Nimu |

У розмові бажаною є двоскладова форма, якщо з контексту вже зрозуміло, що йдеться про місяць. Еталонна вимова має **слабке виділення першого складу**; наголос не є частиною ідентичності назви.
