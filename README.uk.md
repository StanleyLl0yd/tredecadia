# Tredecadia

[English](README.md) · **Українська** · [Усі мови](README.languages.md)

Tredecadia — відкритий проєкт вічного календаря з **13 місяцями по 28 днів**. Кожен місяць має рівно чотири повні тижні, одна й та сама дата завжди припадає на той самий день тижня, а дні, що вирівнюють тривалість року, винесені за межі місяців і семиденного тижня.

> **Поточна публічна версія: `1.0.0-rc.1`.** Це release candidate: сумісна поверхня v1 уже заморожена, але перед фінальним `v1.0.0` триває період спостереження та перевірки.

## Як це працює

- 13 × 28 = 364 звичайні дні всередині місяців.
- Кожен місяць — рівно чотири повні тижні.
- День `01` завжди понеділок, `28` — неділя.
- `EQ` — День рівнодення / Новий рік — відкриває рік і не належить ані місяцю, ані тижню.
- У високосний рік після `13-28` додається `ED` — День Землі — і лише потім настає наступний `EQ`.

Звичайний рік:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

Високосний рік:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Ера Tredecadia

Tredecadia використовує одну безперервну цілочисельну шкалу років зі справжнім **нулевим роком**. Усередині календаря немає потреби ділити час на BCE/CE.

Математичний початок координат:

`TE 00000-EQ ↔ астрономічний григоріанський рік -9999, 20 березня`

Це відповідає тому, що зазвичай називають **10000 BCE**. Дата не проголошується «початком людства», цивілізації чи будь-якого історичного процесу — це лише математичний нуль шкали Tredecadia.

Для цивільного перетворення:

`рік TE = астрономічний григоріанський рік + 9999`

Тому 2026 рік відповідає **TE 12025**.

## Формат дат

Канонічний машинний формат використовує лише ASCII і щонайменше п’ять цифр у полі року:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

У людському інтерфейсі початкові нулі можна не показувати, а звичайний дефіс замінити типографським мінусом. Це лише спосіб відображення, а не інший канонічний формат.
