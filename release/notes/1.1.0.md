Stable v1.1 is planned as a compatible localization-only minor release derived from published `v1.1.0-rc.1`.

Planned stable promotion:

- preserve the complete canonical v1 calendar identity from `v1.0.0`;
- preserve the existing stable `ru-Cyrl`, `ja-Kana`, and `ko-Hang` month profiles unchanged;
- explicitly decide each of the six reviewed RC profiles: `ka-Geor`, `hy-Armn`, `ar-Arab`, `hi-Deva`, `bn-Beng`, and `fa-Arab`;
- introduce no weekday aliases;
- change only release version/status metadata and the maturity of explicitly accepted profiles.

Publication remains blocked until the RC observation is complete, has no compatibility-critical/open defects, and every reviewed profile has an explicit accept/reject decision.
