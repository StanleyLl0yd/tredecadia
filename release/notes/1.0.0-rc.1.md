# Tredecadia 1.0.0-rc.1

This is the first v1 release candidate of Tredecadia, an open 13 × 28 perennial calendar standard.

The release candidate freezes the intended v1 compatibility surface for testing: the 13×28 calendar structure, Tredecadia Era and civil conversion, `EQ`/`ED` semantics, canonical date grammar, canonical month order/names/Short-6/Short-4 forms, pronunciation identity, and conservative Short-4 recognition policy.

It also includes three independently reviewed, non-stable localization profiles (`ru-Cyrl`, `ja-Kana`, `ko-Hang`), strict signed-year/accessibility guidance, a dependency-free Python reference converter, Draft 2020-12 schema validation, executable compatibility checks, and deterministic release packaging.

The attached `tredecadia-1.0.0-rc.1.tar.gz` is generated deterministically from the release source set. `SHA256SUMS` contains its SHA-256 digest. The archive embeds `RELEASE-MANIFEST.json` listing every included source file.

This is a prerelease. Localization profiles remain `reviewed`, not `stable`; final promotion and registry stabilization are reserved for `v1.0.0` after RC feedback and final review.
