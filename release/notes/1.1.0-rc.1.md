# Tredecadia 1.1.0-rc.1

This compatible v1.1 release candidate adds six reviewed month-display localization profiles without changing Tredecadia v1 canonical calendar identity.

New reviewed month profiles:

- `ka-Geor` — Georgian Mkhedruli
- `hy-Armn` — Eastern Armenian
- `ar-Arab` — fully vocalized Arabic
- `hi-Deva` — Hindi-oriented Devanagari
- `bn-Beng` — Bengali
- `fa-Arab` — Iranian Persian

The existing stable `ru-Cyrl`, `ja-Kana`, and `ko-Hang` profiles are carried forward unchanged. The six new profiles remain `reviewed` during the release-candidate phase; stable promotion requires an explicit later decision.

Canonical month and weekday names, month numbers/order, `W1..W7`, date grammar, Tredecadia Era, epoch, leap rule, and conversion semantics are unchanged from `v1.0.0`. Weekday aliases are not introduced.
