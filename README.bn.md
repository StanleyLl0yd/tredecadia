# Tredecadia

[English](README.md) · **বাংলা** · [সব ভাষা](README.languages.md)

Tredecadia হলো একটি উন্মুক্ত স্থায়ী ক্যালেন্ডার প্রকল্প, যেখানে বছরে **২৮ দিনের ১৩টি মাস** থাকে। প্রতিটি মাস ঠিক চার সপ্তাহের, তাই একই তারিখ প্রতি বছর সাপ্তাহিক চক্রের একই অবস্থানে পড়ে। বছরের দৈর্ঘ্য সামঞ্জস্য করার অতিরিক্ত দিনগুলো মাস ও সাত দিনের সাপ্তাহিক চক্র—দুটোরই বাইরে থাকে।

> **বর্তমান প্রকাশ্য সংস্করণ: `1.1.0-rc.1`।**

## মূল কাঠামো

- 13 × 28 = মাসের ভেতরে 364টি নিয়মিত দিন।
- প্রতিটি মাসে ঠিক চারটি পূর্ণ সপ্তাহ।
- প্রতি মাসের `01` সবসময় **Mene (`W1`)**, `28` সবসময় **Toze (`W7`)**।
- `EQ` — **বিষুব / নববর্ষ দিবস** — বছর শুরু করে এবং কোনো মাস বা সপ্তাহের অংশ নয়।
- অধিবর্ষে `13-28`-এর পরে অতিরিক্ত `ED` — **পৃথিবী দিবস** — থাকে; তার পরেই পরের বছরের `EQ` আসে।

মানক সাত দিনের চক্র:

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

এগুলো Tredecadia-এর মানক পরিচয়, সোমবার থেকে রবিবারের অনুবাদ বা নতুন নাম নয়। RC2-এ সপ্তাহের দিনের জন্য এখনো স্বাধীনভাবে পর্যালোচিত স্থানীয় উপনাম নির্ধারিত হয়নি, তাই মানক লাতিন রূপই ব্যবহৃত হয়।

সাধারণ বছর:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

অধিবর্ষ:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Tredecadia যুগ

Tredecadia বছর গণনার জন্য একটি ধারাবাহিক পূর্ণসংখ্যার অক্ষ ব্যবহার করে, যেখানে প্রকৃত **বছর 0** রয়েছে। ফলে ক্যালেন্ডারের ভেতরে সময়কে দুই আলাদা যুগে ভাগ করার দরকার হয় না।

ইংরেজি সংক্ষিপ্ত রূপ **BCE/CE** এসেছে **Before Common Era / Common Era** থেকে; বাংলায় এর অর্থ **সাধারণ যুগের পূর্বে / সাধারণ যুগ**।

গাণিতিক সূচনাবিন্দু:

`TE 00000-EQ ↔ জ্যোতির্বৈজ্ঞানিক গ্রেগরিয়ান বছর -9999, 20 মার্চ`

প্রচলিত ঐতিহাসিক লেখায় এটি **সাধারণ যুগের পূর্বে 10000 (`10000 BCE`)**-এর সমতুল্য। এর অর্থ মানবসভ্যতা বা কোনো ঐতিহাসিক যুগের “শুরু” নয়; এটি কেবল Tredecadia বছরের স্থানাঙ্কের গাণিতিক শূন্যবিন্দু।

নাগরিক রূপান্তরের জন্য:

`TE বছর = জ্যোতির্বৈজ্ঞানিক গ্রেগরিয়ান বছর + 9999`

তাই সাধারণ যুগের 2026 সাল হলো **TE 12025**।

## তারিখের বিন্যাস

ব্যবস্থার মধ্যে আদান-প্রদানের মানক বিন্যাস কেবল ASCII ব্যবহার করে এবং বছর অন্তত পাঁচ অঙ্কের হয়:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

ব্যবহারকারী-মুখী ইন্টারফেসে শুরুর শূন্য বাদ দেওয়া যেতে পারে এবং ঋণাত্মক বছরের জন্য মুদ্রণগত ঋণচিহ্ন ব্যবহার করা যেতে পারে। এগুলো শুধু প্রদর্শনের ধরন, আলাদা মানক পরিচয় নয়।
