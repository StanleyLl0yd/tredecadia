# Tredecadia

[English](README.md) · **한국어** · [모든 언어](README.languages.md)

Tredecadia는 **28일짜리 13개월**로 이루어진 개방형 영구 달력 프로젝트입니다. 모든 달이 정확히 4주이므로 같은 날짜는 해마다 같은 주 내 위치에 놓입니다. 한 해의 길이를 맞추는 특별한 날짜는 달과 7일 주기 바깥에 둡니다.

> **현재 공개 버전은 `1.0.0-rc.2`입니다.** 두 번째 출시 후보판은 국제적으로 중립적인 것을 목표로 설계한 정규 요일 이름을 도입합니다. 정식 `v1.0.0`은 RC2 전용 관찰 기간과 최종 검토를 마친 뒤에만 공개할 수 있습니다.

## 기본 구조

- 13 × 28 = 달 안에 들어가는 일반 날짜 364일.
- 모든 달은 정확히 4주입니다.
- 매달 `01`은 항상 **Mene (`W1`)**, `28`은 항상 **Toze (`W7`)**입니다.
- `EQ`는 **춘분 / 새해의 날**로, 한 해를 시작하며 어느 달에도 어느 요일에도 속하지 않습니다.
- 윤년에는 `13-28` 다음에 `ED`, **지구의 날**이 하나 더 들어가고, 그 뒤에 다음 해의 `EQ`가 옵니다.

정규 7일 주기:

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

이 이름들은 Tredecadia의 정규 식별자이며 월요일부터 일요일까지의 번역이나 이름 변경이 아닙니다. RC2에서는 요일에 대해 검토된 한국어 표시 별칭을 아직 정의하지 않으므로 정규 라틴 표기를 그대로 사용합니다.

평년:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

윤년:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Tredecadia 연대

Tredecadia는 실제 **0년**을 포함하는 하나의 정수형 연도 축을 사용합니다. 따라서 달력 내부에서는 시대를 둘로 나눌 필요가 없습니다.

영어의 **Before Common Era / Common Era**를 줄여 **BCE/CE**라고 합니다. 한국어로는 보통 각각 **기원전 / 서기**에 해당합니다.

수학적 원점은 다음과 같습니다.

`TE 00000-EQ ↔ 그레고리력 천문학적 연도 -9999년 3월 20일`

일반적인 역사 표기로는 **기원전 10000년(10000 BCE)**에 해당합니다. 이 날짜를 인류나 문명의 시작으로 주장하는 것은 아닙니다. Tredecadia 연도 좌표를 정하기 위한 수학적 0점일 뿐입니다.

민간 변환 규칙은 다음과 같습니다.

`TE 연도 = 그레고리력 천문학적 연도 + 9999`

따라서 서기 2026년은 **TE 12025**입니다.

## 날짜 표기

기계 교환용 정규 형식은 엄격한 ASCII를 사용하며 연도는 최소 5자리입니다.

`12025-07-11` · `00000-EQ` · `-00001-01-01`

사용자 화면에서는 앞의 0을 생략하거나 음수 연도에 조판용 마이너스 기호를 써도 됩니다. 이는 표시 방식일 뿐 다른 정규 식별자는 아닙니다.

## 월 이름

한국어에는 검토가 끝난 한글 표기 프로필이 있습니다. 표에서는 한글 표기를 먼저 쓰고, 괄호 안에 변하지 않는 정규 라틴 표기를 함께 적습니다.

| # | 정식 이름 | 3음절 축약형 (`Short-6`) | 2음절 회화형 (`Short-4`) |
|---:|---|---|---|
| 01 | 마사누미카 (`Masanumika`) | 마사누 (`Masanu`) | 마사 (`Masa`) |
| 02 | 타수주누무 (`Tasuzunumu`) | 타수주 (`Tasuzu`) | 타수 (`Tasu`) |
| 03 | 나주마사누 (`Nazumasanu`) | 나주마 (`Nazuma`) | 나주 (`Nazu`) |
| 04 | 미카수마니 (`Mikasumani`) | 미카수 (`Mikasu`) | 미카 (`Mika`) |
| 05 | 야니무주누 (`Yanimuzunu`) | 야니무 (`Yanimu`) | 야니 (`Yani`) |
| 06 | 주미타나수 (`Zumitanasu`) | 주미타 (`Zumita`) | 주미 (`Zumi`) |
| 07 | 무야사누미 (`Muyasanumi`) | 무야사 (`Muyasa`) | 무야 (`Muya`) |
| 08 | 수니주사카 (`Sunizusaka`) | 수니주 (`Sunizu`) | 수니 (`Suni`) |
| 09 | 누마나무타 (`Numanamuta`) | 누마나 (`Numana`) | 누마 (`Numa`) |
| 10 | 카주누수야 (`Kazunusuya`) | 카주누 (`Kazunu`) | 카주 (`Kazu`) |
| 11 | 야나주마사 (`Yanazumasa`) | 야나주 (`Yanazu`) | 야나 (`Yana`) |
| 12 | 사누미카주 (`Sanumikazu`) | 사누미 (`Sanumi`) | 사누 (`Sanu`) |
| 13 | 니무타주나 (`Nimutazuna`) | 니무타 (`Nimuta`) | 니무 (`Nimu`) |

대화에서는 월을 말하고 있다는 점이 분명할 때 2음절 회화형을 우선 사용합니다. 기준 발음은 **첫 음절을 약하게 두드러지게** 하는 정도이며, 강세 자체는 이름의 식별 요소가 아닙니다.

한글 표기는 한국어 음운 체계에 맞춘 표시용 적응이며, Tredecadia의 정규 음절열 자체를 바꾸지 않습니다.
