# Tredecadia

[English](README.md) · **Русский** · [Все языки](README.languages.md)

Tredecadia — открытый проект вечного календаря: **13 месяцев по 28 дней**, одинаковая структура каждого месяца и постоянное соответствие дат дням недели. Дни, которыми календарь доводится до длины солнечного года, вынесены за пределы месяцев и семидневной недели.

> **Текущая публичная версия: `1.0.0-rc.2`.** Второй кандидат вводит международно нейтральные канонические названия дней недели. Стабильный `v1.0.0` может быть опубликован только после отдельного периода наблюдения RC2 и финальной проверки.

## Как устроен календарь

- 13 × 28 = 364 обычных дня внутри месяцев.
- Каждый месяц — ровно четыре полные недели.
- `01` всегда **Mene (`W1`)**, `28` всегда **Toze (`W7`)**.
- `EQ` — **День равноденствия / Новый год** — открывает год и не относится ни к месяцу, ни к неделе.
- В високосный год после `13-28` появляется дополнительный `ED` — **День Земли** — и только затем наступает `EQ` следующего года.

Канонический семидневный цикл:

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

Эти названия — канонические идентификаторы Tredecadia, а не переименования григорианских понедельника–воскресенья. Проверенных русских алиасов для дней недели в RC2 пока нет, поэтому используется каноническая латиница.

Обычный год:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

Високосный год:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Эра Tredecadia

Tredecadia использует одну непрерывную целочисленную шкалу лет с настоящим **нулевым годом**. Внутри календаря не требуется деление на «до нашей эры» и «нашу эру». Международные английские обозначения этих двух частей шкалы — **Before Common Era / Common Era**, сокращённо **BCE/CE**.

Математическое начало координат:

`TE 00000-EQ ↔ астрономический григорианский год -9999, 20 марта`

В привычной исторической записи это **10000 год до н. э.** (`10000 BCE`). Эта дата не объявляется «началом человечества», цивилизации или какой-либо исторической эпохи. Это только математический ноль шкалы лет Tredecadia.

Для гражданского преобразования:

`год TE = астрономический григорианский год + 9999`

Поэтому 2026 год н. э. соответствует **TE 12025**.

## Формат дат

Каноническая машинная запись использует строгий ASCII и не менее пяти цифр в поле года:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

В интерфейсах для людей ведущие нули можно не показывать, а обычный дефис перед отрицательным годом заменить типографским знаком минуса. Это только оформление, не другой машинный формат.

## Месяцы

Для русского языка существует проверенный кириллический профиль. В таблице сначала приведено русское написание, а в скобках — неизменяемое каноническое латинское имя.

| № | Полное имя | Краткая форма, 3 слога (`Short-6`) | Разговорная форма, 2 слога (`Short-4`) |
|---:|---|---|---|
| 01 | Масанумика (`Masanumika`) | Масану (`Masanu`) | Маса (`Masa`) |
| 02 | Тасузунуму (`Tasuzunumu`) | Тасузу (`Tasuzu`) | Тасу (`Tasu`) |
| 03 | Назумасану (`Nazumasanu`) | Назума (`Nazuma`) | Назу (`Nazu`) |
| 04 | Микасумани (`Mikasumani`) | Микасу (`Mikasu`) | Мика (`Mika`) |
| 05 | Янимузуну (`Yanimuzunu`) | Яниму (`Yanimu`) | Яни (`Yani`) |
| 06 | Зумитанасу (`Zumitanasu`) | Зумита (`Zumita`) | Зуми (`Zumi`) |
| 07 | Муясануми (`Muyasanumi`) | Муяса (`Muyasa`) | Муя (`Muya`) |
| 08 | Сунизусака (`Sunizusaka`) | Сунизу (`Sunizu`) | Суни (`Suni`) |
| 09 | Нуманамута (`Numanamuta`) | Нумана (`Numana`) | Нума (`Numa`) |
| 10 | Казунусуя (`Kazunusuya`) | Казуну (`Kazunu`) | Казу (`Kazu`) |
| 11 | Яназумаса (`Yanazumasa`) | Яназу (`Yanazu`) | Яна (`Yana`) |
| 12 | Санумиказу (`Sanumikazu`) | Сануми (`Sanumi`) | Сану (`Sanu`) |
| 13 | Нимутазуна (`Nimutazuna`) | Нимута (`Nimuta`) | Ниму (`Nimu`) |

В разговоре предпочтительна двухсложная краткая форма, если из контекста уже понятно, что речь идёт о месяце. Эталонное произношение использует **слабое выделение первого слога**; ударение не является частью идентичности имени.

Русские `ми` и `ни` естественно произносятся с мягкими согласными. Это допустимая русская фонетическая адаптация, а не изменение канонического имени.
