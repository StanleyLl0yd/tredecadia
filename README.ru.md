# Tredecadia

[English](README.md) · **Русский** · [Все языки](README.languages.md)

Tredecadia — это открытый проект вечного календаря: **13 месяцев по 28 дней**, одинаковая структура каждого месяца и стабильное соответствие дат дням недели. Дни, которые выравнивают год по солнечному циклу, вынесены за пределы месяцев и семидневной недели.

> **Текущая публичная версия: `1.0.0-rc.1`.** Это release candidate: совместимая поверхность v1 уже заморожена, но окончательный `v1.0.0` будет выпущен только после периода наблюдения и проверки RC.

## Как устроен календарь

- 13 × 28 = 364 обычных дня внутри месяцев.
- Каждый месяц — ровно четыре полные недели.
- `01` всегда понедельник, `28` всегда воскресенье.
- `EQ` — День равноденствия / Новый год — открывает год и не относится ни к месяцу, ни к неделе.
- В високосный год после `13-28` появляется дополнительный `ED` — День Земли — и только затем наступает следующий `EQ`.

Обычный год:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

Високосный год:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Эра Tredecadia

Внутри Tredecadia используется одна непрерывная целочисленная шкала лет с настоящим **нулевым годом**. Деление на BCE/CE календарю не требуется.

Математическое начало координат:

`TE 00000-EQ ↔ астрономический григорианский год -9999, 20 марта`

Это соответствует тому, что обычно называют **10000 BCE**, но дата не объявляется «началом человечества» или какой-либо исторической эпохи. Это просто удобный математический ноль.

Для гражданского преобразования:

`год TE = астрономический григорианский год + 9999`

Поэтому 2026 год соответствует **TE 12025**.

## Формат дат

Каноническая машинная запись — строгий ASCII и минимум пять цифр в поле года:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

В интерфейсах для людей нули слева можно не показывать, а обычный дефис заменить типографским минусом. Это только оформление, не альтернативный машинный формат.
