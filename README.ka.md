# Tredecadia

[English](README.md) · **ქართული** · [ყველა ენა](README.languages.md)

Tredecadia არის ღია პროექტი მუდმივი კალენდრისთვის, რომელიც შედგება **13 თვისგან, თითოეული 28 დღით**. ყოველ თვეში ზუსტად ოთხი სრული კვირაა, ამიტომ თვის ერთი და იგივე თარიღი ყოველთვის კვირის ციკლის იმავე პოზიციაზე მოდის. წლის სიგრძის შესასწორებელი დამატებითი დღეები მოთავსებულია თვეებისა და შვიდდღიანი კვირის ციკლის გარეთ.

> **მიმდინარე საჯარო ვერსიაა `1.1.0-rc.1`.**

## ძირითადი სტრუქტურა

- 13 × 28 = თვეებში მოქცეული 364 ჩვეულებრივი დღე.
- ყოველ თვეში ზუსტად ოთხი სრული კვირაა.
- ყოველი თვის `01` ყოველთვის არის **Mene (`W1`)**, ხოლო `28` — **Toze (`W7`)**.
- `EQ` — **ბუნიობის / ახალი წლის დღე** — ხსნის ყოველ წელს და არ ეკუთვნის არც ერთ თვეს და არც კვირის ციკლს.
- ნაკიან წელიწადში `13-28`-ის შემდეგ ემატება `ED` — **დედამიწის დღე** — და მხოლოდ ამის შემდეგ იწყება მომდევნო წლის `EQ`.

კანონიკური შვიდდღიანი ციკლი:

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

ეს სახელები Tredecadia-ს კანონიკური იდენტიფიკატორებია და არა ორშაბათიდან კვირამდე არსებული სახელების თარგმანი ან გადარქმევა. RC2-ში კვირის დღეებისთვის შემოწმებული ქართული საჩვენებელი ალტერნატიული სახელები ჯერ განსაზღვრული არ არის, ამიტომ გამოიყენება კანონიკური ლათინური ფორმები.

ჩვეულებრივი წელიწადი:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

ნაკიანი წელიწადი:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Tredecadia-ს ერა

Tredecadia წლებისთვის იყენებს ერთ უწყვეტ მთელრიცხვიან ღერძს, რომელშიც არსებობს ნამდვილი **0 წელი**. ამიტომ კალენდარს შიგნით დროის ორ ცალკე ეპოქად დაყოფა არ სჭირდება.

ინგლისური შემოკლებები **BCE/CE** ნიშნავს **Before Common Era / Common Era**. ქართულ ისტორიულ ჩანაწერებში მათ ქრონოლოგიურად ჩვეულებრივ შეესაბამება **ძვ. წ. / ახ. წ.**

მათემატიკური საწყისი წერტილია:

`TE 00000-EQ ↔ ასტრონომიული გრიგორიანული წელი -9999, 20 მარტი`

ჩვეულებრივ ისტორიულ ჩანაწერში ეს შეესაბამება **10000 ძვ. წ.-ს (`10000 BCE`)**. ეს თარიღი არ ცხადდება კაცობრიობის, ცივილიზაციის ან რომელიმე ისტორიული პროცესის „დასაწყისად“; ის მხოლოდ Tredecadia-ს წლების კოორდინატის მათემატიკური ნულია.

სამოქალაქო გარდაქმნისთვის:

`TE წელი = ასტრონომიული გრიგორიანული წელი + 9999`

ამიტომ ახ. წ. 2026 წელი შეესაბამება **TE 12025**-ს.

## თარიღის ფორმატი

კანონიკური გაცვლის ფორმატი იყენებს მკაცრ ASCII-ს და წლის ველი მინიმუმ ხუთნიშნაა:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

ადამიანისთვის განკუთვნილ ინტერფეისებში დასაწყისი ნულები შეიძლება გამოტოვდეს, ხოლო უარყოფითი წლებისთვის გამოყენებულ იქნეს ტიპოგრაფიული მინუსის ნიშანი. ეს მხოლოდ გამოსახვის ფორმებია და არა ალტერნატიული კანონიკური იდენტიფიკატორები.
