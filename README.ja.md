# Tredecadia

[English](README.md) · **日本語** · [すべての言語](README.languages.md)

Tredecadia は、**1年を28日×13か月**で構成するオープンな永久暦プロジェクトです。どの月も4週間ちょうどなので、同じ日付は毎年同じ週内位置になります。年の長さを調整する特別な日は、月にも7日周期の週にも属しません。

> **現在の公開版は `1.1.0-rc.1` です。**

## 基本構造

- 13 × 28 = 月に属する通常日が364日。
- 1か月は常に4週間です。
- 各月の `01` は必ず **Mene (`W1`)**、`28` は必ず **Toze (`W7`)** です。
- `EQ` は **春分・新年の日**で、その年を開きます。月にも曜日にも属しません。
- うるう年には `13-28` の後に `ED`、**地球の日**が入り、その次に翌年の `EQ` が来ます。

正規の7日周期：

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

これらは Tredecadia の正規識別子であり、月曜日から日曜日までの翻訳名や改名ではありません。RC2 では曜日について審査済みの日本語表示エイリアスをまだ定義していないため、正規ラテン表記をそのまま使用します。

通常年：

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

うるう年：

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Tredecadia 紀年

Tredecadia の年は、**0年を含む1本の整数軸**で数えます。そのため、暦の内部では「紀元前」と「紀元後」を別々の仕組みとして扱う必要がありません。

英語で一般的に使われる **Before Common Era / Common Era** の略が **BCE/CE** です。日本語では通常、BCE は「紀元前」、CE は「西暦（共通紀元）」に相当します。

数学上の原点は次のとおりです。

`TE 00000-EQ ↔ グレゴリオ暦の天文学的年番号 -9999年 3月20日`

一般的な歴史表記では **紀元前10000年（10000 BCE）**に相当します。ただし、これを人類や文明の「始まり」とみなすわけではありません。Tredecadia の年座標を定義するための数学的なゼロ点です。

民用変換では：

`TE年 = グレゴリオ暦の天文学的年番号 + 9999`

したがって西暦2026年は **TE 12025** です。

## 日付表記

機械交換用の正規形式は厳密な ASCII で、年は最低5桁です。

`12025-07-11` · `00000-EQ` · `-00001-01-01`

人向けの表示では先頭のゼロを省いたり、負の年に組版用のマイナス記号を使ったりできます。これは見せ方の違いであり、別の正規形式ではありません。

会話では、月の話だと分かっている場面なら2音節の短縮形を優先します。基準発音では**第1音節を弱く目立たせる**程度で、アクセント位置そのものは月名の識別条件ではありません。

カタカナ表記は日本語として自然に発音できるようにした表示上の適応であり、Tredecadia の正規音列そのものを変更するものではありません。
