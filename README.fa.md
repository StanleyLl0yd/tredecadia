# Tredecadia

[English](README.md) · **فارسی** · [همهٔ زبان‌ها](README.languages.md)

Tredecadia یک پروژهٔ باز برای تقویمی دائمی با **۱۳ ماهِ ۲۸روزه** است. هر ماه دقیقاً چهار هفته دارد، بنابراین یک تاریخ مشخص همیشه روی همان روز هفته می‌افتد. روزهایی که طول سال را تنظیم می‌کنند خارج از ماه‌ها و خارج از چرخهٔ هفت‌روزهٔ هفته قرار می‌گیرند.

> **نسخهٔ عمومی فعلی: `1.0.0-rc.1`.** این نسخه نامزد انتشار است؛ سطح سازگاری v1 از حالا ثابت شده، اما پیش از انتشار نهایی `v1.0.0` یک دورهٔ مشاهده و بازخورد در نظر گرفته شده است.

## ساختار اصلی

- 13 × 28 = 364 روز عادی داخل ماه‌ها.
- هر ماه دقیقاً چهار هفتهٔ کامل است.
- روز `01` همیشه دوشنبه و روز `28` همیشه یکشنبه است.
- `EQ` — روز اعتدال / سال نو — آغاز هر سال است و به هیچ ماه یا روز هفته‌ای تعلق ندارد.
- در سال کبیسه، پس از `13-28` یک روز اضافه با نام `ED` — روز زمین — می‌آید و سپس `EQ` سال بعد آغاز می‌شود.

سال عادی:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

سال کبیسه:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## دورهٔ Tredecadia

Tredecadia از یک محور عدد صحیح پیوسته برای سال‌ها استفاده می‌کند و **سال 0 واقعی** دارد. بنابراین داخل خود تقویم نیازی به دو بخش BCE/CE نیست.

مبدأ ریاضی:

`TE 00000-EQ ↔ سال نجومی گریگوری -9999، 20 مارس`

این تقریباً همان چیزی است که معمولاً **10000 BCE** نامیده می‌شود. این تاریخ «آغاز بشر» یا تمدن یا هیچ دورهٔ تاریخی خاصی اعلام نمی‌شود؛ فقط نقطهٔ صفر ریاضی مختصات سال Tredecadia است.

برای تبدیل مدنی:

`سال TE = سال نجومی گریگوری + 9999`

در نتیجه سال 2026 برابر با **TE 12025** است.

## قالب تاریخ

قالب استاندارد تبادل فقط از ASCII استفاده می‌کند و بخش سال حداقل پنج رقم دارد:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

در رابط کاربری می‌توان صفرهای آغازین را حذف کرد و از علامت منفی تایپوگرافیک استفاده کرد. این‌ها فقط شیوهٔ نمایش‌اند و قالب استاندارد دیگری محسوب نمی‌شوند.
