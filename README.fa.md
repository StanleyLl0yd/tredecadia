# Tredecadia

[English](README.md) · **فارسی** · [همهٔ زبان‌ها](README.languages.md)

Tredecadia یک پروژهٔ باز برای تقویمی دائمی با **۱۳ ماهِ ۲۸روزه** است. هر ماه دقیقاً چهار هفته دارد، بنابراین یک تاریخ مشخص همیشه در همان جایگاه چرخهٔ هفته قرار می‌گیرد. روزهایی که طول سال را تنظیم می‌کنند خارج از ماه‌ها و خارج از چرخهٔ هفت‌روزهٔ هفته قرار می‌گیرند.

> **نسخهٔ عمومی فعلی: `1.1.0-rc.1`.**

## ساختار اصلی

- 13 × 28 = 364 روز عادی داخل ماه‌ها.
- هر ماه دقیقاً چهار هفتهٔ کامل است.
- روز `01` همیشه **Mene (`W1`)** و روز `28` همیشه **Toze (`W7`)** است.
- `EQ` — **روز اعتدال / سال نو** — آغاز هر سال است و به هیچ ماه یا روز هفته‌ای تعلق ندارد.
- در سال کبیسه، پس از `13-28` یک روز اضافه با نام `ED` — **روز زمین** — می‌آید و سپس `EQ` سال بعد آغاز می‌شود.

چرخهٔ هفت‌روزهٔ معیار:

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

این نام‌ها شناسه‌های معیار Tredecadia هستند، نه ترجمه یا تغییر نام دوشنبه تا یکشنبه. RC2 هنوز نام‌های نمایشیِ محلیِ بازبینی‌شده‌ای برای روزهای هفته تعریف نمی‌کند، بنابراین شکل‌های لاتین معیار استفاده می‌شوند.

سال عادی:

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

سال کبیسه:

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## دورهٔ Tredecadia

Tredecadia از یک محور عدد صحیح پیوسته برای سال‌ها استفاده می‌کند و **سال 0 واقعی** دارد. بنابراین داخل خود تقویم نیازی به تقسیم زمان به دو دورهٔ جدا نیست.

اختصارهای انگلیسی **BCE/CE** از عبارت‌های **Before Common Era / Common Era** می‌آیند؛ در فارسی می‌توان آن‌ها را **پیش از دوران مشترک / دوران مشترک** در نظر گرفت.

مبدأ ریاضی:

`TE 00000-EQ ↔ سال نجومی گریگوری -9999، 20 مارس`

در شیوهٔ رایج تاریخی، این برابر با **سال 10000 پیش از دوران مشترک (`10000 BCE`)** است. این تاریخ «آغاز بشر» یا تمدن یا هیچ دورهٔ تاریخی خاصی اعلام نمی‌شود؛ فقط نقطهٔ صفر ریاضی مختصات سال Tredecadia است.

برای تبدیل مدنی:

`سال TE = سال نجومی گریگوری + 9999`

در نتیجه سال 2026 دوران مشترک برابر با **TE 12025** است.

## قالب تاریخ

قالب استاندارد تبادل فقط از ASCII استفاده می‌کند و بخش سال حداقل پنج رقم دارد:

`12025-07-11` · `00000-EQ` · `-00001-01-01`

در رابط کاربری می‌توان صفرهای آغازین را حذف کرد و برای سال‌های منفی از علامت منفی تایپوگرافیک استفاده کرد. این‌ها فقط شیوهٔ نمایش‌اند و قالب استاندارد دیگری محسوب نمی‌شوند.
