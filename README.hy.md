# Tredecadia

[English](README.md) · **Հայերեն** · [Բոլոր լեզուները](README.languages.md)

Tredecadia-ն **13 ամսից՝ յուրաքանչյուրում 28 օր**, կազմված մշտական օրացույցի բաց նախագիծ է։ Յուրաքանչյուր ամիս ունի ճիշտ չորս ամբողջական շաբաթ, ուստի ամսվա նույն ամսաթիվը միշտ ընկնում է շաբաթվա ցիկլի նույն դիրքին։ Տարվա տևողությունը հավասարակշռող լրացուցիչ օրերը գտնվում են ամիսներից և յոթօրյա շաբաթական ցիկլից դուրս։

> **Ընթացիկ հրապարակային տարբերակը `1.0.0-rc.2` է։** Երկրորդ թողարկման թեկնածուն ներմուծում է շաբաթվա օրերի կանոնական անուններ, որոնք նախագծված են միջազգային չեզոքության նպատակով։ Կայուն `v1.0.0` տարբերակը կարող է հրապարակվել միայն RC2-ի առանձին դիտարկման շրջանի և վերջնական ստուգման ավարտից հետո։

## Հիմնական կառուցվածքը

- 13 × 28 = ամիսների ներսում 364 սովորական օր։
- Յուրաքանչյուր ամիս ունի ճիշտ չորս ամբողջական շաբաթ։
- Յուրաքանչյուր ամսվա `01`-ը միշտ **Mene (`W1`)** է, իսկ `28`-ը՝ **Toze (`W7`)**։
- `EQ` — **գիշերահավասարի / Նոր տարվա օրը** — բացում է տարին և չի պատկանում ոչ մի ամսվա կամ շաբաթվա ցիկլի։
- Նահանջ տարում `13-28`-ից հետո ավելացվում է `ED` — **Երկրի օրը** — և միայն դրանից հետո սկսվում է հաջորդ տարվա `EQ`-ը։

Կանոնական յոթօրյա ցիկլը՝

`W1 Mene → W2 Noko → W3 Kese → W4 Zoyo → W5 Sote → W6 Yemo → W7 Toze`

Այս անունները Tredecadia-ի կանոնական նույնացուցիչներն են, ոչ թե երկուշաբթիից կիրակի օրերի անունների թարգմանություններ կամ վերանվանումներ։ RC2-ում շաբաթվա օրերի համար ստուգված հայերեն ցուցադրական այլընտրանքային անուններ դեռ սահմանված չեն, ուստի օգտագործվում են կանոնական լատինատառ ձևերը։

Սովորական տարի՝

`Y-EQ → Y-01-01 → … → Y-13-28 → (Y+1)-EQ`

Նահանջ տարի՝

`Y-EQ → Y-01-01 → … → Y-13-28 → Y-ED → (Y+1)-EQ`

## Tredecadia-ի դարաշրջանը

Tredecadia-ն տարիների համար օգտագործում է մեկ շարունակական ամբողջ թվային սանդղակ, որն ունի իրական **0 տարի**։ Այդ պատճառով օրացույցի ներսում ժամանակը երկու առանձին դարաշրջանների բաժանելու կարիք չկա։

Անգլերեն **BCE/CE** հապավումները նշանակում են **Before Common Era / Common Era**։ Հայերեն պատմական գրառումներում դրանց ժամանակագրական համարժեքներն են **մ. թ. ա. / մ. թ.**

Մաթեմատիկական սկզբնակետը՝

`TE 00000-EQ ↔ աստղագիտական Գրիգորյան տարի -9999, մարտի 20`

Սովորական պատմական գրառմամբ դա համապատասխանում է **մ. թ. ա. 10000 թվականին (`10000 BCE`)**։ Այս ամսաթիվը չի ներկայացվում որպես մարդկության, քաղաքակրթության կամ որևէ պատմական գործընթացի «սկիզբ»․ այն միայն Tredecadia-ի տարեթվերի կոորդինատի մաթեմատիկական զրոն է։

Քաղաքացիական փոխարկման համար՝

`TE տարի = աստղագիտական Գրիգորյան տարի + 9999`

Ուստի մ. թ. 2026 թվականը համապատասխանում է **TE 12025**-ին։

## Ամսաթվի ձևաչափը

Կանոնական փոխանակման ձևաչափը օգտագործում է խիստ ASCII, իսկ տարվա դաշտն ունի առնվազն հինգ թվանշան՝

`12025-07-11` · `00000-EQ` · `-00001-01-01`

Օգտատիրոջ համար նախատեսված միջերեսներում սկզբի զրոները կարելի է չցուցադրել, իսկ բացասական տարիների համար կարելի է օգտագործել տպագրական մինուսի նշանը։ Դրանք միայն ցուցադրման տարբերակներ են, ոչ թե այլ կանոնական նույնացուցիչներ։

## Ամիսները

Ամիսների անունները անփոփոխ միջազգային նույնացուցիչներ են։ Հայկական գրի համար դրանց անկախ ստուգված գրության պրոֆիլ դեռ չկա, ուստի այստեղ միտումնավոր պահպանվում է **կանոնական լատինատառ գրությունը**, և ինքնակամ հայերեն ձևեր չեն ստեղծվում։
